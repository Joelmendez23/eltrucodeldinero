# Política de privacidad

Última actualización: 28 de octubre de 2026

**El Truco del Dinero Automation** es una herramienta privada que usa el propietario del canal de YouTube *El Truco del Dinero* para gestionar su propio canal.

## Qué datos usa
La herramienta accede, mediante la API oficial de YouTube y con autorización OAuth de Google, únicamente a la cuenta de YouTube del propietario para:
- subir y publicar videos del propio canal;
- leer información básica del canal;
- leer las estadísticas de YouTube Analytics del propio canal.

No accede a datos de otras personas ni de los espectadores más allá de las estadísticas agregadas que YouTube ofrece al propietario del canal.

## Cómo se guardan
Las credenciales y los datos se guardan solo en el equipo del propietario. No se venden, no se comparten con terceros y no se usan para publicidad.

## Uso de datos de Google
El uso de la información recibida de las APIs de Google cumple la [Política de Datos de Usuario de los Servicios de API de Google](https://developers.google.com/terms/api-services-user-data-policy), incluidos los requisitos de uso limitado.

La herramienta también usa los Servicios API de YouTube. Al usarla, se aplican los [Términos de Servicio de YouTube](https://www.youtube.com/t/terms) y la [Política de Privacidad de Google](https://policies.google.com/privacy).

## Cómo revocar el acceso
El acceso se puede retirar en cualquier momento desde la página de permisos de la cuenta de Google: [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
